# Pembuat Kalender BKJTK

Pembuat kalender meja 21 x 14 cm (sampul + 12 bulan, depan-belakang) dalam satu file HTML statis. Tanpa backend dan tanpa build; foto disimpan di browser pengguna (IndexedDB).

Live: https://kalender-bkjtk.vercel.app

Deploy: `vercel deploy --prod` dari folder yang berisi `index.html`.
